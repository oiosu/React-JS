##### (1) 배열  생성

* 배열 생성자 

  ```javascript
  let arrA = new Array(); // 배열 생성자
  ```

* 배열 리터럴 (대부분 사용)

  ```javascript
  llet arrB = [];
  ```



```javascript
let arrC = [
  1,
  2,
  3,
  true,
  "hello",
  null,
  undefined,
  () => {},
  {},
  [],
];

```

> 얼마든지 저장하고 싶은 데이터를 쉽게 순차적으로 보관이 가능하다.
