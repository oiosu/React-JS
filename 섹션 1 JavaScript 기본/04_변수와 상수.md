**(1) 변수**

```javascript
let age = 28;
console.log(age);
```

> age라는 변수에, 변수에 담긴 값인 숫자 값인 28이다. 
>
> * `let age = 28;` 변수를 선언한다. 
> * `let age = 28;` 저장하는 이 과정을 변수의 초기 값을 넣는다고 해서 초기화 한다 라고 불린다. 
> * 변수에 28이라는 값을 담아두게 되면 앞으로 값을 age라는 변수의 이름으로 불러와 사용할 수 있다. 

> 변수는 이렇게 언제든 값을 바꿀 수 있기 때문에 선언 할  초기 값이 없는, 즉 초기화가 이루어지지 않는 변수도 당연히 선언이 가능하다. 

> 변수라는 건 프로그램이 실행되는 도중에 게속 값을 바꿔가면서 값을 저장할 수 있는 저장소라고 이해하면 된다. 



**(2) 상수** 

> 상수는 변수와는 달리 한번 저장된 값을 다시는 바꿀 수 없다. 

```javascript
const birth = "1997.04.16";
```

> 상수는 생일처럼 변할 수 없거나 아니면 앞으로 변하지 말아야 되는 그런 값들을 저장할 때 변수 대신에 자주 사용하게 된다. 

> 참고로 이 상수는 값을 변화시키는 것 자체가 불가능 하기 떄문에 이런 초기화가 반드시 필요하다. 

> 상수는 선언 이후에는 다시는 값을 넣어줄 수가 없기 떄문에 무조건 선언과 동시에 초기 값을 할당하는 초기화를 반드시 해줘야 한다. 라고 기억하기  



**(3) 변수 명명규칙 (네이밍 규칙)**

* `$` , `_` 제외한 기호는 사욯할 수 없다. 

  ```javascript
  let $_name;
  ```

* 숫자로 시작할 수 없다. 

  ```javascript
  let name1;
  let $2name;
  ```

* 예약어를 사용할 수 없다. 

  ```javascript
  let, for, if .....
  ```



**(4) 변수 명명 가이드**

```javascript
let salesCount = 1;
let refundCount = 1;
let totalSalesCount = salesCount - refundCount;
```
