##### (1) **함수**

```javascript
//함수 선언 

//1번
function greeting(){
    //4번
    console.log("안녕하세요!")
}

//2번
console.log("호출 전");
//3번
greeting();
//5번
console.log("호출 후");
```

> 함수를 선언했다고 실행되는 것이 아니다. 함수의 이름을 불러서 함수를 호출했을 때만 실행이 된다. 
>
> `greeting()`
>
> * 함수를 호출할때는 반드시 소괄호를 함께 작성해야 한다. 
> * 함수가 호출되면 프로그램의 실행 순서가 함수 내부로 넘어가게 된다. 
>   * 숫자 순으로 포탈을 이동하는 것처럼 함수 내부로 넘어가게 된다. 
>   * `호출 전`  / `안녕하세요!` / `호출 후` 이렇게 출력된다. 



##### (2) 직사각형 넓이를 구하는 함수

```javascript
// 이렇게 전달된 인수들을 순서대로 저장하는 이런 특수한 함수의 변수들을 
// 매개변수라고 한다. 
function getArea(width, height) {
    let area = width * height;
    
    console.log(area);
}

getArrea(10, 20);
// width에 10, height에 20
// 이렇게 함수를 호출하면서 함수에게 전달 한 값들을 각각
// 인수라고 한다. 
```

> * 인수 : 함수를 호출하면서 함수에게 전달 한 값 
> * 매개변수 : 전달된 인수들을 순서대로 저장하는 특수한 함수의 변수들 



##### (3) 동적으로 함수에서 쓸 값들을 계속 바꿔가면서 넘겨줄 수 있는 함수

````javascript
function getArea(width, height) {
    let area = width * height;
    
    // return 이후에 작성된 값을 반환하게 된다. 
    // 이값을 바로 반환 값이라고 한다. 
    // 이 값이 곧 함수의 호출의 결과 값이 된다. 
    return area;
    // 참고로 함수가 return 문을 만나게 되면 그냥 값을 반환하게 된다. 
    //retrun문 밑에 코드를 추가적으로 작성하게 되면 코드는 실질적으로 수행이 되지 않는다. 
    // console.log("hellooo")
}

// 그렇기 때문에 반환 값을 변수에 담아서 활용이 가능하다. 
let area1 = getArea(10, 20);
let area2 = getArea(30, 20);
let area3 = getArea(10, 20);
````

> 200 이라는 값을 반환하는데 이 값은 곧 이 함수 호출의 결과 값이 되어서 
>
> 결국 area1이라는 변수에 200이라는 값이 저장 될 것이다.

##### (5) 자바스크립트의 호이스팅 기능 

```javascript
let area1 = getArea(10, 20);
console.log(area1);

let area2 = getArea(30, 20);
console.log(area2);

getArea(120, 200);

// 호이스팅
// -> 끌어올리다 라는 뜻
function getArea(width, height) {
  function another() {
    // 중첩 함수
    console.log("another");
  }

  another();
  let area = width * height;

  return area;
}
```

> 선언문을 호출문보다 아래에 두어도 내부적으로 호이스팅이 되어서 끌어올려져서 실행이 가능하다. 
>
> 호이스팅 덕분에 함수 선언이 무조건 위에 있지 않아도 되기때문에 좀 더 유연하게 프로그래밍을 진행 할 수 있다는 장점이 있다.
