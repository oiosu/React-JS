### 06_형 변환 (Type Casting)

* **형 변환 (Type Casting)**
  * 어떤 값의 타입을 다른 타입으로 변경하는 것을 말한다. 

![image](https://github.com/oiosu/React-JS/assets/99783474/acd0e577-7222-4c5a-9239-425266f7469e)




* **묵시적 형변환, 명시적 형 변환**

| 묵시적 형 변환                                               | 명시적 형 변환                                  |
| ------------------------------------------------------------ | ----------------------------------------------- |
| (암묵적 형 변환), 개발자가 직접 설정하지 않아도 알아서 자바스크립트 엔진이 형 변환 하는 것을 말함 | 개발자가 직접 함수 등을 이용해 형 변환을 일으킴 |

> 묵시적은 내가 생각지도 못하게 바뀔 수 있는것이고 명시적은 내가 시켜야만 바뀌는 것이라고 이해하면 된다. 



**(1)  묵시적 형 변환** 

> 자바스크립트 엔진이 알아서 형 변환 하는 것 

```javascript
let num = 10;
let str = "20";

const result = num + str;
```

> `num + str` 숫자와 문자열을 더하는 불가능한 연산을 작성하게 되면 자바스크립트 엔진이 오류를 발생시키지 않기 위해서 `num` 숫자를 암묵적으로 또는 묵시적으로 형을 변환하게 된다. 

> 하지만 모든 불가능한 연산에 묵시적 형 변환이 잘 일어나는 것은 아니다. 

> 특정 하나의 변수의 값을 `num` 이라는 변수 하나의 값만 형 변환했을 경우 오류가 발생하지 않고 연산이 잘 종료가 되는 경우에 변환이 일어나는 것이다. 



**(2) 명시적 형 변환** 

> 프로그래머 내장함수 등을 이용해서 직접 형 변환을 명시한다. 
>
> * 내장함수? 
>   * 자바스크립트가 기본적으로 제공하는 함수를 말한다. 

```javascript
let str1 = "10";
let strToNum1 = Number(str1);
console.log(10 + strToNum1);

let str2 = "10개";
let strToNum2 = parseInt(str2);
```

> `parseInt` 사용시 숫자가 앞쪽으로 나와 있어야 한다. 



```javascript
let num1 = 20;
let numToStr1 = String(num1);

console.log(numToStr1 + "입니다");
```
