### 08_연산자(2)



**(1) null 병합 연산자** 

> 존재하는 값을 추려내는 기능을 한다. 
>
> null, undefined가 아닌 값을 찾아 내는 연산자. 

```javascript
let var1;
let var2 = 10;
let var3 = 20;

let var4 = var1 ?? var2;
// var1는 undefined, var2는 10이기 때문에 
// 10이 출력된다. 

let var5 = var1 ?? var3;
let var6 = var3 ?? var2;
```

```javascript
let var6 = var2 ?? var3;
```

> null 병합 연산자에 참여하는 두 개의 p-연산자가 둘다 null 이나 undefined이 아니다 라고 한다면 맨 처음에 적힌 `var2` 이 반환이 된다. 



##### ✅ 회원 관리 시스템

```javascript
let userName = "임수경";
let userNickName = "Ready";

let displayName = userName;
```

> 만약 userName이라는 변수의 값이 존재한다면 userName을 displayeName에 저장하고, Undefined 라면(없다면) 그때는 userNickName으로 저장하기 
>
> ```javascript
> let displayName = userName ?? userNickName;
> console.log(displayName)
> ```



**(2) typeof 연산자**

> 값의 타입을 문자열로 반환하는 기능을 하는 연산자 
>
> 자바스크립트는 독특하게 변수를 선언하면서 숫자 값으로 변수를 처음에 초기화 하더라도 해당 변수의 다른 타입의 값을 나중에 또 저장하는게 가능하다 (변수의 타입이 고정되어 있지 않다.)
>
> ```javascript
> let var7 = 1;
> var7 = "hello";
> ```



만약, 현재 변수에 저장된 값의 타입이 궁금하다면 typeof 연산자를 이용하면 된다. 

```javascript
let t1 = typeof var7;
//string
```



**(3) 삼항 연산자** 

> 항을 3개 사용하는 연산자 
>
> 조건식을 이용해서 참, 거짓일 때 값을 다르게 반환한다. 

```javascript
let var8 = 10;

// 요구사항 : 변수 res에 var8의 값이 짝수 -> "짝", 홀수 -> "홀"

let res = var8 % 2 === 0 ? "짝수" : "홀수";

console.log(res);
```

> `var8 % 2 === 0 ` 첫번째 조건식 
>
> `?` 뒤에 `:` 을 기준으로 왼쪽에는 참일 때의 반환 값, 세번째 항에는 거짓일때의 반환 값을 작성하기 

> 참이라면 짝수라는 값을 res에 저장하고 만약에 참이 아니라면 홀수라는 값을 res에 저장하기
