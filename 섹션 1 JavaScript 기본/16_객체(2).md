### 15_객체(2)

#### Object 심화내용



##### (1) 상수 객체

* 말뜻 그대로 상수에 저장해 놓은 객체

```javascript
const animal = {
  type: "고양이",
  name: "나비",
  color: "black",
};

animal.age = 2; // 추가
animal.name = "까망이"; // 수정
delete animal.color; // 삭제
```

> 상수에 저장된 객체도 프로퍼티를 추가하거나 수정하거나 삭제하는 게 가능하다. 
>
> 왜? 상수라는 것은 엄밀히 말하자면 새로운 값을 할당하지 못하는 변수라 말한다. 하지만 저장되어 있는 객체 값의 프로퍼티를 수정하는건 아무런 문제가 되지 않는다. 
>
> 그렇기 떄문에 상수에 객체를 보관한다고 하더라도 프로퍼티를 추가, 수정, 삭제 조작은 얼마든지 가능하다.  



##### (2) 메서드

* 값이 함수인 프로퍼티를 말한다. 

```javascript
const person = {
  name: "임수경",
  // 메서드 선언
  sayHi() {
    console.log("안녕!");
  },
};

person.sayHi();
// 안녕!
person["sayHi"]();
// 안녕!
```

> 이러한 메서드는 객체의 동작을 정의하는데 사용이 된다. 
>
> = 프로퍼티들은 메서드로써 객체의 동작을 정의한다. 라고 이해를 하면 된다.
