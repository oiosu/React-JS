### 09_조건문

* 조건문 (Conditional Statement) 란?
  * 특정 조건을 만족 했을 때에만 실행되는 코드를 작성한기 위한 문법 
  * 대표적으로 if, switch 조건문이 존재함 

![image-20240420202411084](https://raw.githubusercontent.com/oiosu/image_repo/master/img/image-20240420202411084.png)



**(1) IF조건문**

```javascript
let num = 10;

if (num >= 10){
    //조건식이 만족했을 때 수행할 코드들을 이 안에 작성하기
    console.log("num은 10이상입니다.");
    //코드를 연달아 코드 작성 가능 
    console.lgo("조건이 참 입니다!")
} else if (num >= 5) {
  //   console.log("num은 5 이상입니다");
} else if (num >= 3) {
  //   console.log("num은 3 이상입니다");
} else {
  //   console.log("조건이 거짓입니다!");
}
```

> * `else if` 문의 갯수는 여러번 작성이 가능하다. 
>
> * `if`로 시작해서 `else`로 끝내야 한다. 



**(2) switch**

```javascript
let animal = "owl";

switch (animal) {
//case를 적고 animal 변수 후보에 대해 적어준다.
  case "cat": {
    console.log("고양이");
    break;
  }
  case "dog": {
    console.log("강아지");
    break;
  }
  case "bear": {
    console.log("곰");
    break;
  }
  case "snake": {
    console.log("뱀");
    break;
  }
  case "tiger": {
    console.log("호랑이");
    break;
  }
  // 어떠한 케이스에도 해당되지 않았을 떄 실행할 코드를 만들어준다.
  default: {
    console.log("그런 동물은 전 모릅니다");
  }
}
```

> *  `if` 보다 다수의 조건을 처리할 떄 `switch`  문이 적합하다. 
>
> * `if`문과 기능 자체는 동일
> * `switch` `case` 문은 기본적으로 소괄호 안에 있는 변수의 값과 일치하는 케이스를 위부터 아래로 차례대로 탐색을 한다. 탐색을 하다가 일치하는 케이스를 만나게 되면그 아래에 있는 모든 코드를 수행한다. 
> * 따라서 `break`를 작성하여 멈추게 해줘야 한다. 
> * `switch`문은 기본적으로 거의 모든 케이스에 브레이크를 필수적으로 해줘야 한다.
