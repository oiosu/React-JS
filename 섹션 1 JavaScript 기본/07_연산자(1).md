### 07_연산자(1)

* **연산자(Operator)?**
  * 프로그래밍에서의 다양한 연산을 위한 기호, 키워드를 말한다. 


![image](https://github.com/oiosu/React-JS/assets/99783474/0d210c6a-5ea4-456e-b695-f032ccf59ce4)




**(1) 대입 연산자** 

```javascript
let var1 = 1;
```



**(2) 산술 연산자**

```javascript
let num1 = 3 + 2;
let num2 = 3 - 2;

// 연산 우선순위가 높다. 
let num3 = 3 * 2;
let num4 = 3 / 2;
let num5 = 3 % 2;
```



**(3) 복합 대입 연산자** 

> 산술 연산자와 대입 연산자가 복합되어 있다. 

```javascript
let num7 = 10;
num7 += 20;
num7 -= 20;
num7 *= 20;
num7 /= 20;
num7 %= 10;
```

> `num7 += 20;`  : 원래 num7의 값에 20을 추가해라 라는 뜻으로 이해하면 된다. 



**(4) 증감 연산자** 

```javascript
let num8 = 10;
++num8;
num8++;
```

> 값을 1씩 늘리거나 또는 1씩 줄일 때 쓰는 연산자 이다. 

> `++num8;` 변수명 앞에 증감 연산자를 붙이면, 그 라인에서 즉시 연산이 이루어진다.
>
> 앞에 증감 연산자를 붙이는것을 **전위 연산** 이라고도 한다. 
>
> 그 반대말로 **후위 연산**이라고도 한다. 
>
> 덧셈 말고도 뺄셈으로도 사용이 가능하다.



**(5) 논리 연산자** 

```javascript
let or = true || false;

let and = true && false;

let not = !true;
```



**(6) 비교 연산자** 

```javascript
let comp1 = 1 === "1";
let comp2 = 1 !== 2;

let comp3 = 2 > 1;
let comp4 = 2 < 1;

let comp5 = 2 >= 2;
let comp6 = 2 <= 2;
```
