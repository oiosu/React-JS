### 12_함수 표현식과 화살표 함수



##### (1) 함수 자체를 변수에 담을 수 있다. 

```javascript
function funcA() {
    console.log("funca");
}

let varA = funcA;
console.log(varA);

//출력 결과
f funcA() {
    console.log("funca");
}
```

> 자바스크립트에서는 이렇게 함수도 숫자나 문자열과 같은 하나의 값으로서 취급하기 때문에 함수 자체를 변수에 담을 수 있다. 



##### (2) 함수 표현식

```javascript
let varB = function funcB() {
	console.log("funcB");
};

varB();
```

> 함수를 선언하지 않고 변수에 담듯이 `varB` 는 `function funcB` 함수 라는 식을 만드는 것도 가능하다. 
>
> **👻 주의할 점 👻**
>
> : 이런 경우는 선언식이 아니다, 선언식이라는 건 어떤 변수의 값으로써 담기지 않은 상태로 유지가 되어야 하는데 이 경우는 그냥 값으로써 함수가 생성이 된 것이기 때문에 함수의 이름으로는 호출(`funcB()`)이 불가능 하다. 
>
> ✅ 따라서 이렇게 함수를 생성할 때는 이름을 생략해도 전혀 문제가 생기지 않는다. 
>
> ```javascript
> let varB = function() {
> 	console.log("funcB");
> };
> 
> varB();
> ```
>
> : 이렇게 이름이 없는 함수를 `익명 함수` 라고 한다. 





* 호이스팅이 되는 함수 선언문으로 만든 funcA와 달리 함수 표현식으로 만든 함수들은 호이스팅의 대상이 되지 않는다.  



##### (3) 화살표 함수

```javascript
let varC = () => 1;

console.log(varC());
```

```javascript
//매개변수가 필요하다면 
let varC = (value) => value + 1;

console.log(varC(10));
```

```javascript
//일반적인 함수와 동작 
let varC = (value) => {
  console.log(value);
  return value + 1;
};

console.log(varC(10));
```
