### 01_Hello JavaScript

* HTML의 역할 
  * 요소들의 내용, 배치, 모양을 정하기 위해 사용하는 언어 
  * 색상이나 디자인 등의 수정은 불가 
* CSS의 역할 
  * 요소들의 색상, 크기 등의 스타일을 설정 할 수 있음 
* JavaScript의 역할 
  * 웹 내부에서 발생하는 다양한 기능을 만들 수 있는 언어 
  * 웹을 움직이게 하는 "웹의 근육"이라고 표현할 수 있음 



* JavaScript는 `JavaScript 엔진` 에 의해 실행된다. 

  * `JavaScript 엔진` 는 브라우저에 기본 탑재되어 있다 

  * 따라서 웹 브라우저를 이용하면 간단한 JavaScript 코드를 직접 실행 가능하다.

    ```javascript
    console.log("안녕 자바스크립트")
    ```
