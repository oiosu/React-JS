### 15_객체(1)

#### Object? 

* 원시 타입이 아닌 객체 타입의 자료형
* 여러가지 값을 동시에 저장할 수 있는 자료형을 의미한다. 

![image-20240502180338517](https://raw.githubusercontent.com/oiosu/image_repo/master/img/image-20240502180338517.png)

* 객체를 이용하면  현실세계에 존재하는 어떤 사물이나 개념을 표현하기 용이하다. 

```javascript
let person = {
    name : "su kyung",
    nickname : "ready",
    age: 28,
    location: "강서구", 
};
```



##### (1) 객체 생성

* 객체 생성자 

``` javascript
let obj1 = new Object();
```

* 객체 리터럴 (대부분 사용하는 코드)

```javascript
let obj2 = {}; 
```



##### (2) 객체 프로퍼티 (객체 속성)

```javascript
let person = {
  name: "임수경",
  age: 28,
  hobby: "음앇감상",
  job: "FE Developer",
  extra: {},
  10: 20,
  "like cat": true,
};
```

> 이러한 프로퍼티들은 객체의 실실적인 정보를 담고 있는 역할을 한다. 

> `name: "임수경"` ,,,,`key : value`
>
> 프로퍼티의 key 가 name인 것이고 value는 문자열 임수경 인 것이다.



##### (3) 객체 프로퍼티를 다루는 방법 

* 3-(1) 특정 프로퍼티에 접근 (점 표기법, 괄호 표기법)

  ```javascript
  let name = person.name;
  let age = person["age2"];
  
  let property = "hobby";
  let hobby = person[property];
  
  let property = "hobby";
  let hobby = person[property];
  ```

  > 존재하지 않는 프로퍼티에 접근하려고 하면 `undefined` 이라는 값이 출력된다. 
  >
  > `person[age]` 라고 작성하면 age를 변수로 인식해서 오류가 발생한다. 



* 3-(2) 새로운 프로퍼티를 추가하는 방법 

  ```javascript
  person.job = "fe developer";
  person["favoriteFood"] = "떡볶이";
  
  console.log(person);
  ```

  > 전 표기법이나 괄호 표기법을 이용해서 없던 프로퍼티 값을 할당할 수 있다. 



* 3-(3) 프로퍼티를 수정하는 방법 

  ```javascript
  person.job = "educator";
  person["favoriteFood"] = "초콜릿";
  ```



* 3-(4) 프로퍼티를 삭제하는 방법 

  ```javascript
  delete person.job;
  delete person["favoriteFood"];
  ```



* 3-(5) 프로퍼티의 존재 유무를 확인하는 방법 (in 연산자 )

  ```javascript
  let result1 = "name" in person;
  let result2 = "cat" in person;
  console.log(result2);
  ```
