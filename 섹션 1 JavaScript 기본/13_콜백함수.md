### 13_콜백함수

#### 👻 Callback Function

* 자신이 아닌 다른 함수에, 인수로써 전달된 함수를 의미한다. 

```javascript
function main(value) {
    value();
}
function sub(){
    console.log("sub");
}

main(sub);
```

> `main` 과 `sub` 이라는 2개의 함수 생성 
>
> main 함수는 value 라는 매개변수를 받고 아래에 선언된 서브 함수는 매개변수는 없고 대신 console에 서브라는 문자열을 출력을 하고 있다. 
>
> 이때 `main(sub);` 메인 함수를 호출하면서 인수로는 서브라는 값을 전달해준다면
>
> (sub 라는 값은 우리가 위에 선언해둔 sub 함수이다.)
>
> 그렇다면 메인 함수의 value라는 매개변수는 에는 sub이라는 함수가 들어오게 된다.
>
> ---
>
> 그렇기 때문에 이런 식으로 value 매개변수에 저장된 함수를 메인 함수 안에서 호출이 가능하다. 왜냐하면 value라는 매개변수 안에는 sub이라는 함수가 저장이 되어있기 때문이다. 
>
> ---
>
> 실행 결과는 `sub` 이 출력된다. 
>
> ---
>
> `main(sub);`  : 함수에 인수로써 이렇게 전달되 이러한 함수를 ⭐ 콜백함수 라고 부른다.





##### (1) 콜백함수

```javascript
function masin(value) {
    console.log(value);
    //이렇게 호출도 가능하다.
    //value();
}

function sub() {
    console.log("i am sub");
}

main(sub);
```

> 콘솔에 서브 함수 그 자체가 출력이 되는 것을 알 수 있다. 

> 어떠한 함수를 다른 함수의 인수로 전달해서 호출시키도록 이렇게 함수에서 알아서 호출하도록 설정한 서브와 같은 함수를 `콜백 함수` 라고 한다. 



##### (2) 왜 콜백함수라고 할까?

* 콜백이라는 것이 프로그래밍에서는 뒤에 실행되는 또는 나중에 실행된다는 뜻으로  사용된다. 

* 따라서 바로 실행되는 것이 아닌 위 코드 처럼 메인 함수에 인수로 전달이 되어서 나중에 이 메인 함수가 알아서 실행하게 된다라고 해서 콜백함수라고 한다. 

* 메인 함수에서는 전달된 콜백 함수를 자기가 원하는 타이밍에 호출이 가능하다. 

  * ```javascript
    function masin(value) {
        console.log(1);
        console.log(2);
        value();
    }
    
    function sub() {
        console.log("i am sub");
    }
    
    main(sub);
    ```

    > 출력 결과 
    >
    > 1 
    >
    > 2 
    >
    > i am sub

    ---

    > callback 콜백 함수는 메인 함수가 언젠든지 원하는 타이밍에 실행시킬 수 있다는 점 알아두기 



##### (3) 함수 표현식 응용

```javascript
function main(value){
    console.log(1);
    console.log(2);
    value();
    console.log("end");
}
main(function(){
    console.log("i am sub");
});
```

* ```javascript
  main(function(){
      console.log("i am sub");
  });
  ```

  > 선언문 자체를 안으로 넣어서 함수 표현식 처럼 사용 가능 (= 익명함수)



##### (4) 화살표 함수 응용

```javascript
main(() => {
    console.log("i am sub");
});
```

> 화살표 함수가 메인 함수의 콜백 함수로써 인수로 전달이 된다. 



##### (5) 콜백함수 활용(콜백함수를 언제 사용할 수 있을까?)

```javascript
function repeat(count) {
    for(let idx = 1; idx <= count; idx++) {
        console.log(idx);
    }
}

function reateDouble(count) {
    for(let idx = 1; idx <= count; idx++) {
        console.log(idx * 2);
    }
}

repeat(5);
repeatDouble(5); // 2의 배수가 출력된다. 
```

> ⭐ repeat과 repeat double 처럼 구조가 거의 흡사한 이런 함수들을 만들게 될 일이 굉장히 많다. 

> 하지만 이런 방법이 계속 된다면 반복되는 코드로 좋지 않은 방식으로 작업할 경우가 많다. 
>
> ⭐ 따라서 이런 경우 콜백함수를 이용하면 된다. 



##### ✅ 좋은 코드 

```javascript
function repeat(count, callback) {
  for (let idx = 1; idx <= count; idx++) {
    callback(idx);
  }
}

repeat(5, (idx) => {
  console.log(idx);
});

repeat(5, (idx) => {
  console.log(idx * 2);
});

repeat(5, (idx) => {
  console.log(idx * 3);
});
```

> callback이라는 매개변수를 받도록 해준다. 
>
> 반복문 안에는 콘솔의 idx를 출력하는 것이 아닌 콜백 함수를 호출하고 인수로 idx를 넘겨주도록 한다. 
>
> repeat 함수에서 반복물이 돌면서 매 반복마다 callback 함수를 호출하면서 idx로 1부터 5까지 전달해줬기 때문에 콘솔이 1부터 5까지 출력이 된것이라고 이해하기
