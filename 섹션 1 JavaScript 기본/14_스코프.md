### 14_스코프

#### Scope ? 

* 우리 말로 "범위"를 뜻한다. 
* 변수나 함수에 접근하거나 호출할 수 있는 범위를 말한다. 

```javascript
function funcA(){
    let a = 1;
}
console.log(a);
```

* `Uncaught ReferenceError : a is not defined` a 라는 변수는 모릅니다 라는 오류가 발생 

* 이유 : func라는 함수 바깥에서는 지금 변수 a를 알 방법이 알지 못하기 때문에 접근이 불가능한 것이다. 
*  a 라는 변수에 접근할 수 있는 범위 즉, 스코프는 이 함수 낼부로만 한정이 되기 때문에 함수 바깥에서는 a라는 변수에 접근이 불가능하다.

> `let a = 1;` 변수 a는 func a 라는 지역 스코프를 갖는다 또는 지역적인 스코프를 갖는다 라고 표현 할 수 있다. 



##### (1) 스코프

* 전역 스코프 : 전체 영역에서 접근 가능

  ```javascript
  let a = 1;
  ```

* 지역 스코프 : 특정 영역에서만 접근 가능

  ```javascript
  let a = 1; // 전역 스코프
  
  function funcA() {
    let b = 2; // 지역 스코프
    console.log(a);
  }
  ```

  

* 조건문은 함수와 마찬가지로 중괄호를 통해서 블럭을 만든다. 선언된 모든 변수들은 다 지역 스코프를 갖는다라고 이해할 수 있다. 
* 선언된 변수들은 모두 다 지역 스코프를 갖기 때문에 중괄호 바깥에서는 접근할 수 없다. 

```javascript
let a = 1; // 전역 스코프

function funcA() {
  let b = 2; // 지역 스코프
  console.log(a);
}

funcA();

if (true) {
  let c = 1;
}

for (let i = 0; i < 10; i++) {
  let d = 1;
}

funcB();
```
