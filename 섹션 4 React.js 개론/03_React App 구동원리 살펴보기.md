### 03_React App 구동원리 살펴보기

* vite를 통해 생성한 리액트 앱에는 웹 서버가 내장되어 있다.

* 리액트 앱을 가동하기 위해 사용했었던 `npm run dev` 라는 명령은 리액트 서버를 가동시키는 명령어 이다. 

* 리액트 앱 서버를 가동시켰을 때 콘솔에 메세지는 리액트 앱 서버의 가동이 시작되었다는 뜻이다. 

  ![image-20240616190038542](https://raw.githubusercontent.com/oiosu/image_repo/master/img/image-20240616190038542.png)

* 메세지와 함께 출력되었던 `localhost:5173` 이라는 주소는 현재 가동 중인 리액트 웹 서버에 접속할 수 있는 주소이다. 



##### ✅ localhost 의 의미 

: 우리 컴퓨터를 의미한다. (컴퓨터의 주소)

 : 그렇기 때문에 웹 브라우저에서 localhost 5173 이라는 주소록 접속한다는 것은 localhost가 내 컴퓨터를 의미한다고 했기에 브라우저에서 내 컴퓨터에서 실행되고 있는 리액트 웹 서버에 접속요청을 보낸다 라고 이해하면 된다. 

: 참고로 localhost 뒤에 콜론과 함께 나오는 5173이라는 번호는 포트 번호이다.

 : 포트 번호는 하나의 컴퓨터 내에서 여러 대의 서버를 동작시키기 위해 필요한 그런 주소 체게이다. 

: 포트 번호가 필요한 이유는 하나의 PC에서 여러 개의 서버가 동작하고 있을 때 주소로만 요청을 받게 되면 어떠한 서버가 이 요청에 응답해야 되는지가 굉장히 모호하기 때문에 이런 상황을 막기 위해 컴퓨터는 모든 프로그램이 실행이 될 때마다 자동으로 고유한 포트 번호를 붙여준다.
