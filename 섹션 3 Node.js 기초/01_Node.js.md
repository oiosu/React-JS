### 01_Node.js

* Next.js, Vue.js 또는  Svelte 까지 모두 Node.js를 기반으로 동작하는 기술들이기때문에 Node.js에 대한 기본적인 이해가 없다면 리액트를 배운다고 해도 제대로 이해하기 어려울 수 있다.
* Node.js는 웹 브라우저가 아닌 환경에서도 자바스크림트 코드를 실행시켜주는 자바스크립트의 런타임, 즉 자바스크립트의 실행 환경이다.

##### 🤔 JavaScript 실행 환경 (Run Time) = 구동기 

> 구동기 : 기본적으로 무언가를 동작시키는 기계 또는 프로그램 
>
> * Node.js 도 자바스크립트를 실행시켜주는 구동기 라고 이해하면 된다.
> * 프로그래밍에서는 이러한 언어를 구동하는 구동기를 실행 환경이라고 해서 `런타임` 이라고 표현하기도 한다. 

##### 🤔 JavaScript의 History

> 자바스크립트는 태생 자체가 웹 페이지 내부에 필요한 아주 단순한 기능만을 개발하기 위해 만들어졌다. 
>
> ex)  사용자가 웹에서 버튼을 클릭하면 경고창을 띄어주기 
>
> ex) 요소의 색상을 변경시키거나 아주 단순한 인터랙션을 개발하기 위한 목적 
>
> 으로 오직 웹브라우저 내에서만 동작할 수 있도록 개발이 되었다.

> 이러한 기능을 만드는 걸 넘어서 웹 브라우저 바깥에서도 자바스크립트를 이용해서 프로그램을 만들고 싶어했고 Node.js를 통해서 자바스크립트는 어디서든 동작할 수 있는 아주 범용적인 언어가 되었다.

> 따라서 Node.js는 자바스크립트가 가진 태생적인 한계를 넘어설 수 있게 되었고 그결과 Node.js를 이용해서 자바스크립트로 굉장히 많은 것들을 만들어 낼 수 있게 되었다.
